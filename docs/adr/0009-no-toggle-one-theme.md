# ADR 0009: Digits toggle removed; toy-bright theme

Status: accepted

## Context

The toggle never helped the child. Every header button looked alike, so nothing read as primary.

## Decision

Digits are gone from the chrome. Word numerals and picture quantities carry all meaning. One theme of bright tokens; the parent area is the only other surface.

## Consequences

Widgets keep their digits-mode branches dormant. Schema keeps both flags for old codes. Supersedes the toggle half of 0006.
